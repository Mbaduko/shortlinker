# ShoLink
ShoLink is a lab project completed as part of the **Agile and DevOps Practices** module at **AmaliTech Apprenticeship.**

It demonstrates the application of Agile and Devops practices to build URL shortener service.



## Development Stack
This project is build with the following tools:

- **Node js**
- **Express.js**
- **PostgreSql**
- **Prisma ORM**
